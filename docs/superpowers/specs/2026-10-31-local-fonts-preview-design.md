# 本机字体列表与实时预览设计

## 目标

字体控件列出用户授权后浏览器可访问的本机字体。将鼠标悬停在字体项上时，临时预览对应范围；点击字体项后才正式应用并持久化。

## 实现范围

修改 `client.js` 中现有 `FontSelect` 及其全局和区域调用方，保持当前全局字体与区域字体两种范围。用自定义列表替换原生 `<select>`，因为原生选项的悬浮事件不能可靠支持实时预览。

用户通过字体控件内的明确操作触发 Chromium Local Font Access API `queryLocalFonts()`，以满足用户激活要求并显示浏览器权限提示。将返回结果按字体家族去重、排序；字体列表仅保存在组件运行时，不写入插件配置。选择的字体家族以安全的 CSS 字符串形式应用，同时保留默认/清除选项。

API 不可用、读取失败或用户拒绝授权时，显示简短状态并回退到当前内置字体预设，不阻断字体控件其他功能。悬停预览不调用状态更新、不写入 `localStorage`；全局范围预览整个宿主界面，区域范围仅预览该区域当前匹配的元素及其文本。鼠标离开字体项、关闭列表或卸载控件时清理临时预览。点击项目才更新对应设置并通过现有状态机制持久化。

## 验证

运行 `node --check client.js`。验证现有预设仍可使用；受支持环境中授权后能看到本机字体；悬停分别预览全局/区域范围且移开后恢复；点击后保留新字体；拒绝授权或 API 不可用时回退预设且无残留预览。按插件开发流程递增 `package.json` 版本并重新安装 bundle，最后提醒用户刷新页面验证。
